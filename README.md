# Vastra Vision

An ML project that looks at a photo of an Indian textile and identifies its traditional style, region and history, and shows which visual features it used to decide.

Phase 1 covers six Vastra (textile) styles. Abharana (jewellery) and Kala (art) come later.

## Folder layout

```
vastra-vision/
  cards/              definition card for each style (region, era, technique, visual markers, sources)
  docs/sourcing.md    trust tiers, verified sources, permission message
  data/
    candidates/<style>/  downloaded images waiting for review (not used for training)
    images/<style>/      accepted images: the training set
    rejected/<style>/    images that failed checks or review
    review/              review pages generated by review.py
    metadata.csv         one row per image: status, trust tier, source, license, group

  notebooks/          Colab notebooks (training, Grad-CAM)
```

## Data pipeline

A label is trusted because of where the image came from, not how it looks. See [docs/sourcing.md](docs/sourcing.md).

```
 verified pieces (tier A) ─────────────────────────────────────────────┐
   add_verified.py / video_to_frames.py                                 │
                                                                        ▼
 museums (tier B) + Commons (tier C) ─► quality_filter.py ─► review.py ─► data/images/
   collect_images.py                    size, blur,          you keep      (training set)
   (catalogue must say                  duplicates,          or reject
    "Indian textile")                   cross-style clash
```

Setup, once:

```
pip install -r requirements.txt
```

**1. Verified pieces (tier A, the most important source)**

Photos of a saree whose authenticity you checked:

```
python src/add_verified.py ~/Pictures/mang_s01 --style mangalagiri --group mang_s01 --source "APCO Vijayawada" --proof "GI tag on label"
```

Or a 30–60 second video of it (gives 40–60 sharp frames):

```
python src/video_to_frames.py saree1.mp4 --style mangalagiri --group mang_s01 --proof "GI tag on label"
```

Use a new `--group` for every physical piece, so all its photos stay together when the data is split into train and test sets.

**2. Museums and Commons (tiers B and C)**

```
python src/collect_images.py                 # add --include-vam for the V&A (non-commercial)
python src/quality_filter.py                 # add --clip for AI hints (pip install -r requirements-clip.txt)
python src/review.py                         # builds data/review/<style>.html
```

Open the review page, click images to reject, press **Export decisions**, then:

```
python src/review.py --apply ~/Downloads/review_kalamkari.json
```

## Project rules

1. One domain at a time: Vastra first, then Abharana, then Kala.
2. Every style has a definition card before any images are collected.
3. Tag every image as `artifact` (historical object) or `craft` (made today in the traditional style).
4. Clean data only: verified pieces, museum open access or openly licensed images, with source, license and trust tier recorded for every image.
5. Every history fact has a source and is marked `documented` or `tradition`.
6. The model shows a confidence score and says "not sure" when confidence is low. It never claims an exact century from a photo.
7. Credit the regions and craft communities, and mention GI tags where they apply.
8. Start small: about 5–6 styles per domain.
